Typeset is an optional stylesheet for semantic HTML and rendered Markdown. Add `typeset` to a container and its headings, paragraphs, lists, tables, code, media, and other content elements receive a consistent reading rhythm.

It uses Basecoat's color, radius, and font tokens, supports dark mode and RTL, and requires no JavaScript. It is shipped separately so applications that do not render long-form content do not pay for it.

## Usage

<Steps>
  <Step title="Include CSS">

Import Typeset after Tailwind and a Basecoat style bundle.

```css
@import 'tailwindcss';
@import 'basecoat-css/vega.css';
@import 'basecoat-css/typeset.css';
```

With the CDN, load the optional Typeset build after Basecoat.

<Code
  lang="html"
  code={`<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/basecoat-css@${basecoatVersion}/dist/basecoat.cdn.min.css" />
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/basecoat-css@${basecoatVersion}/dist/typeset.cdn.min.css" />`}
/>

  </Step>
  <Step title="Wrap your content">

Add `typeset` to the element containing your HTML or rendered Markdown.

```html
<article class="typeset">
  <h1>Release notes</h1>
  <p>Everything that changed in this release.</p>
  <h2>Added</h2>
  <ul>
    <li>Typeset support for semantic HTML.</li>
    <li>Configurable reading rhythm.</li>
  </ul>
</article>
```

Typeset does not set a maximum width. Your layout owns the measure, for example with `max-w-2xl`.

  </Step>
</Steps>

## Examples

### Custom presets

Six custom properties control the fonts and reading rhythm. Define as many preset classes as your application needs.

```css
.typeset-chat {
  --typeset-leading: 1.6;
  --typeset-flow: 1em;
}

.typeset-docs {
  --typeset-font-body: var(--font-sans);
  --typeset-font-heading: var(--font-sans);
  --typeset-font-mono: var(--font-mono);
  --typeset-size: 15px;
  --typeset-leading: 1.75;
  --typeset-flow: 1.5em;
}
```

```html
<div class="typeset typeset-chat">
  ...
</div>
<article class="typeset typeset-docs">
  ...
</article>
```

| Property | Default | Purpose |
| --- | --- | --- |
| `--typeset-font-body` | `inherit` | Body text family. |
| `--typeset-font-heading` | `--font-heading` or inherited | Heading family. |
| `--typeset-font-mono` | `--font-mono` | Inline and block code family. |
| `--typeset-size` | `1em` | Base text size. Typeset renders it at `1.125` times this value below `48rem`. |
| `--typeset-leading` | `1.75` | Body line height. |
| `--typeset-flow` | `1.25em` | Space between content blocks. |

### Opting out

Add `not-typeset` or `data-not-typeset` to a subtree that should keep its own component styles. This also excludes automatic flow spacing; add `mt-(--typeset-flow)` when an embedded component follows text.

```html
<article class="typeset">
  <p>This paragraph uses Typeset.</p>
  <div class="card not-typeset mt-(--typeset-flow)">
    <header>
      <h3>Component content</h3>
      <p>This card keeps its Basecoat styles.</p>
    </header>
  </div>
</article>
```

Unlike shadcn/ui, Basecoat does not use `data-slot` markup. Embedded components are therefore excluded explicitly with `not-typeset` or `data-not-typeset`.

### Streaming content

Typeset uses start margins and avoids layout rules based on `:last-child`, `:has()`, or `:empty`. Appending a new block therefore does not restyle blocks that were already rendered, which makes it suitable for streaming chat and progressively rendered Markdown.

### RTL

Logical margins, padding, and borders follow the document direction automatically.
