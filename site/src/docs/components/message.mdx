## Usage

With a [Basecoat style bundle](/installation) loaded, put each message in its own list item. The final child is a content wrapper. Place an optional [Avatar](/components/avatar) before it and a [Bubble](/components/bubble) or ordinary text inside it. Set `data-align="end"` on outgoing messages.

```html
<ol role="list" aria-label="Conversation">
  <li class="message">
    <div>
      <header>Olivia</header>
      <div class="bubble" data-variant="muted">
        <p>I already checked the logs.</p>
      </div>
    </div>
  </li>
</ol>
```

Include the sender as text, visually hidden if necessary. Use a footer for timestamps, delivery status, or actions. Message supplies layout only. Your application owns delivery and retry behavior.
