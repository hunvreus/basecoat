## Usage

<Steps>
  <Step title="Load the styles and scripts">

Load a full Basecoat style bundle, or import `base/base.css`, `components/input.css`, `components/input-otp.css`, and one style pack after Tailwind. Include the Basecoat runtime and `input-otp.js`, or use `all.js`.

  </Step>
  <Step title="Add the input and slots">

Keep one real text input with a label, `name`, and `maxlength`. The visual slots are hidden from assistive technology. Their count must match `maxlength`; group them in `<div>` elements and use an optional decorative SVG between groups.

```html
<div class="input-otp" id="otp-example">
  <input class="input" type="text" name="code" aria-label="Verification code" inputmode="numeric" autocomplete="one-time-code" spellcheck="false" maxlength="6" value="" dir="ltr" />
  <div aria-hidden="true">
    <div>
      <span></span>
      <span></span>
      <span></span>
      <span></span>
      <span></span>
      <span></span>
    </div>
  </div>
</div>
```

  </Step>
</Steps>

Without JavaScript, the ordinary input remains visible and usable. With JavaScript, it remains the single keyboard target and submitted form value. Typing replaces the selected character and advances to the next slot. To replace a filled code with a pasted one, select the whole field first.

`inputmode="numeric"` requests a numeric keyboard. Add `data-filter` to enforce the input’s `pattern` while typing and pasting. Choose a pattern that accepts partial codes, such as `[0-9]+`, and use `minlength` if the form requires a complete code. Use `type="text"` to preserve leading zeroes. Actual SMS autofill depends on the browser, device, and message format.

      <dd>The real form control and keyboard target. Give it an accessible label.</dd>
      <dt><code>&lt;div aria-hidden="true"&gt;</code></dt>
      <dd>
        Wrapper for the decorative visual slots.
        <dl>
          <dt><code>&lt;div&gt;</code></dt>
          <dd>
            A group of slots.
            <dl>
              <dt><code>&lt;span&gt;</code></dt>
              <dd>One visual slot. The total number of spans across groups must match the input's <code>maxlength</code>.</dd>
            </dl>
          </dd>
        </dl>
      </dd>
    </dl>
  </dd>
</dl>

### JavaScript API

Native `input`, `change`, and form `reset` events remain available. After setting `.value` from your application, call `document.getElementById("otp-example").refresh()` to update the slots. No separate value store or custom completion event is needed.
