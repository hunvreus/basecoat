# Code Block

Display code and terminal output with an optional header, line numbers, and copy button.

<CodeBlockExample title="app/api/chat/route.ts" lang="ts" class="max-w-lg" titleIcon="file" wrapControl filename="route.ts" numbered lineClasses={Object.fromEntries([6, 7, 8, 9, 10].map(line => [line, 'bg-foreground/5 forced-colors:outline']))} code={'import { streamText } from "ai"\n\nexport async function POST(request: Request) {\n  const { messages } = await request.json()\n\n  const result = streamText({\n    model: "anthropic/claude-sonnet-4.5",\n    system: "You are a helpful assistant. Answer in one short paragraph.",\n    messages,\n  })\n\n  return result.toUIMessageStreamResponse()\n}'} />

## Usage

<Steps>
  <Step title="Load the styles">

Load a full Basecoat style bundle, or import `base/base.css`, `components/code-block.css`, `components/button.css`, `components/scrollbar.css`, and one style pack after Tailwind.

  </Step>
  <Step title="Add the code block">

Use `.code-block` around native `<pre><code>`. Add a semantic `<header>` or `<footer>` when needed. Use Button for actions and Scroll Area's `.scrollbar` on the focusable `<pre>`.

```html
<div class="code-block">
  <header>
    <span>Terminal</span>
    <div>
      <button type="button" class="btn" data-variant="ghost" data-size="xs" data-copy>Copy</button>
    </div>
  </header>
  <pre class="scrollbar" tabindex="0" aria-label="Terminal output"><code>npm run build</code></pre>
</div>
```

For syntax colors, see [Syntax highlighting](#syntax-highlighting).

  </Step>
  <Step title="Enable copying (optional)">

Add `data-copy` to the button that copies the block. Include the Basecoat runtime and `code-block.js`, or the full `all.js` bundle. Copy uses the Clipboard API, which requires HTTPS or localhost; failure is announced without pretending the copy succeeded. Without JavaScript, the code remains selectable.

  </Step>
</Steps>

### HTML structure

Use a `<span>` for the header title and a `<div>` for actions. An actions `<div>` directly inside `.code-block` floats at the top end, appearing on hover, keyboard focus, or touch devices.

Scrollable code has a CSS edge fade in browsers with scroll-driven animations. Wrapping moves the fade to the vertical axis.

Line numbers are off by default. To opt in, add `data-line-numbers` to `<pre>` and wrap each line in a direct `<span>` inside `<code>`. Preserve real newline characters between lines, including empty lines. CSS counters supply the visual numbers, which are excluded from both native selection and the Copy button. Plain text needs no line wrappers; use them only for numbering, highlighting, or line-specific utilities.

### Actions

The header can hold any buttons or links your app needs. Try **Wrap lines** to switch the lint output between wrapped lines and horizontal scrolling. **Download** saves the output as `lint.log` using a native download link. **Copy** copies the same text to the clipboard. Basecoat handles Copy. Your app supplies the behavior for custom actions.

### Highlighted lines

Apply ordinary utilities to the lines you want to emphasize. This recipe uses `bg-foreground/5` and an outline in forced-colors mode. Unlike upstream’s line variants, these are example classes, not a Code Block API.

<CodeBlockExample numbered copy={false} lineClasses={{ 3: 'bg-foreground/5 forced-colors:outline', 4: 'bg-foreground/5 forced-colors:outline' }} code={"export default {\n  experimental: {\n    reactCompiler: true,\n    viewTransition: true,\n  },\n  images: {\n    remotePatterns: [{ hostname: \"avatars.githubusercontent.com\" }],\n  },\n}"} />

### Diff

Render the patch as text, including its `+` and `-` prefixes, and use utilities for line backgrounds. The prefixes keep changes distinguishable without color. Native selection and the Copy button both copy the displayed patch, including its prefixes. No diff parser or dedicated variants are included.

<CodeBlockExample title="components/greeting.tsx" lineClasses={{ 2: 'bg-destructive/10', 3: 'bg-foreground/5', 4: 'bg-foreground/5', 5: 'bg-foreground/5' }} code={' export function Greeting({ name }: { name: string }) {\n-  return <p>Hello, {name}</p>\n+  return <p className="text-sm text-muted-foreground">\n+    Hello, {name}!\n+  </p>\n }'} />

### Syntax highlighting

Code Block displays plain text by default. To color the keys, strings, and numbers in this JSON example, the docs run [Shiki](https://shiki.style/guide/install) at build time and place its colored spans inside `<pre><code>`. The browser receives ordinary HTML. Basecoat styles the block, and the Shiki theme supplies the token colors.

<CodeBlockExample title="getWeather output" lang="json" copy={false} code={"{\n  \"location\": \"San Francisco\",\n  \"temperature\": 18,\n  \"unit\": \"celsius\",\n  \"conditions\": [\"fog\", \"wind\"]\n}"} />

### RTL
