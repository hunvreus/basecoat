## Usage

<Steps>
  <Step title="Include CSS">

Import Tailwind and a Basecoat style bundle.

```css
@import 'tailwindcss';
@import 'basecoat-css/vega.css';
```

  </Step>
  <Step title="Add your disclosure HTML">

Put the trigger text in a `<summary>` as the first child of `<details>`. The browser manages the open state and handles pointer and keyboard activation. Content opens and closes instantly. The order preview keeps its heading and status outside the disclosure. Its icon-only summary is positioned beside the heading, preserving native keyboard and pointer behavior.

```html
<details>
  <summary>Shipping options</summary>
  <p>Orders ship within two business days.</p>
</details>
```

  </Step>
</Steps>
