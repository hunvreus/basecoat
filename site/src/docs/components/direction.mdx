## Usage

Set `dir="rtl"` on `<html>` for a right-to-left page, or on a container for a single region. Its descendants inherit the direction.

```html
<section lang="ar" dir="rtl">
  <h2>تسجيل الدخول إلى حسابك</h2>
</section>
```

Use logical utilities such as `ps-4` and `text-start` so spacing and alignment follow the direction. For user-entered text, `dir="auto"` lets the browser determine the direction from the content.
