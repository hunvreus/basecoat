## Usage

Load the full Basecoat CSS and JavaScript bundle, or load the runtime and `navigation-menu.js` separately. A custom CSS build needs Popover CSS, Navigation Menu CSS, and a style pack.

```html
<nav class="navigation-menu" aria-label="Main navigation">
  <ul>
    <li><button type="button" aria-expanded="false" aria-controls="nav-docs">Documentation</button></li>
    <li><a href="/about">About</a></li>
  </ul>
  <div data-popover aria-hidden="true">
    <section id="nav-docs" aria-hidden="true">
      <ul><li><a href="/introduction">Introduction</a></li></ul>
    </section>
  </div>
</nav>
```

Dropdowns open on hover or click. Use Left and Right to move between visible, enabled top-level items. Enter, Space, or Down opens a panel and focuses its first link; arrow keys move between panel links. Escape closes the panel and returns focus to its trigger. Each button's `aria-controls` identifies a section inside the shared panel. One level of dropdown links is supported. A trigger’s trailing SVG is treated as a decorative chevron and rotates when its panel opens.

### HTML structure

<dl>
  <dt><code>&lt;nav class="navigation-menu" aria-label="Main navigation"&gt;</code></dt>
  <dd>
    Navigation landmark. Use an accessible label to distinguish it from other navigation landmarks.
    <dl>
      <dt><code>&lt;ul&gt;</code></dt>
      <dd>
        Direct-child list of top-level items.
        <dl>
          <dt><code>&lt;li&gt;</code></dt>
          <dd>
            Contains one dropdown trigger or navigation link.
            <dl>
              <dt><code>&lt;button type="button" aria-controls="&#123; PANEL_ID &#125;" aria-expanded="false"&gt;</code></dt>
              <dd>Dropdown trigger. Its <code>aria-controls</code> matches the corresponding section ID. A trailing decorative SVG rotates when open.</dd>
              <dt><code>&lt;a href="&#123; URL &#125;"&gt;</code></dt>
              <dd>A top-level link without a dropdown.</dd>
            </dl>
          </dd>
        </dl>
      </dd>
      <dt><code>&lt;div data-popover aria-hidden="true"&gt;</code></dt>
      <dd>
        Shared panel container. JavaScript updates its visibility.
        <dl>
          <dt><code>&lt;section id="&#123; PANEL_ID &#125;" aria-hidden="true"&gt;</code></dt>
          <dd>Content for one trigger. The ID must match that trigger's <code>aria-controls</code>. Put its navigation links inside the section.</dd>
        </dl>
      </dd>
    </dl>
  </dd>
</dl>
