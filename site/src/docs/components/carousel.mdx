## Usage

<Steps>
  <Step title="Include CSS">

Import Tailwind and one full Basecoat style bundle.

```css
@import "tailwindcss";
@import "basecoat-css/vega.css";
```

Or import only the base CSS, Carousel component CSS, and one style pack.

```css
@import "tailwindcss";
@import "basecoat-css/base.css";
@import "basecoat-css/components/carousel.css";
@import "basecoat-css/styles/vega.css";
```

Using CDN or bundler imports? See the [Installation page](/installation).

  </Step>
  <Step title="Include JavaScript">

Copy or serve the full Basecoat JavaScript bundle.

```html
<script src="/assets/js/all.min.js" defer></script>
```

Or copy or serve the Basecoat runtime and Carousel script.

```html
<script src="/assets/js/basecoat.min.js" defer></script>
<script src="/assets/js/carousel.min.js" defer></script>
```

Using CDN or bundler imports? See the [Installation page](/installation).

Basecoat's carousel is built on native CSS scroll snapping instead of [Embla](https://www.embla-carousel.com/), so it swipes and scrolls without JavaScript. The script adds the previous and next buttons, arrow keys, and the JavaScript API. Desktop mouse dragging is not supported; trackpads, touch, and the keyboard work.

The previous and next buttons sit outside the carousel, so leave room for them around it.

### HTML structure

<dl>
  <dt>
    <code>
      &lt;div class="carousel" role="region" aria-roledescription="carousel"
      aria-label="&#123; LABEL &#125;"&gt;
    </code>
  </dt>
  <dd>
    Root carousel container. Supports <code>data-orientation="vertical"</code>,{" "}
    <code>data-align="start|center|end"</code> (default <code>center</code>),{" "}
    <code>data-loop</code>, and{" "}
    <code>data-start-index="&#123; INDEX &#125;"</code> (zero-based position to
    start on).
    <dl>
      <dt>
        <code>&lt;div&gt;</code>
      </dt>
      <dd>
        Scrolling viewport: the direct child that contains the slides.
        <dl>
          <dt>
            <code>
              &lt;div role="group" aria-roledescription="slide" aria-label="1 of
              3"&gt;
            </code>
          </dt>
          <dd>
            A slide. Slides are full width by default; set their size with{" "}
            <code>basis-*</code> utilities.
          </dd>
        </dl>
      </dd>
      <dt>
        <code>&lt;button data-carousel-prev&gt;</code> /{" "}
        <code>&lt;button data-carousel-next&gt;</code>
      </dt>
      <dd>
        Previous and next buttons. They are disabled at the first and last
        positions unless <code>data-loop</code> is set.
      </dd>
    </dl>
  </dd>
</dl>

### JavaScript API

| API                             | Type     | Description                                                                                        |
| ------------------------------- | -------- | -------------------------------------------------------------------------------------------------- |
| `carousel.scrollPrev()`         | Method   | Scrolls to the previous position.                                                                  |
| `carousel.scrollNext()`         | Method   | Scrolls to the next position.                                                                      |
| `carousel.scrollToIndex(index)` | Method   | Scrolls to a zero-based position.                                                                  |
| `carousel.index`                | Property | The current zero-based position.                                                                   |
| `carousel.count`                | Property | The number of positions. Several slides share one position when more than one fits in view.        |
| `carousel.refresh()`            | Method   | Rescans slides and buttons after children change.                                                  |
| `change`                        | Event    | Dispatched when the position or count changes, with `event.detail.index` and `event.detail.count`. |

Arrow keys move between positions while focus is inside the carousel: <kbd>←</kbd> and <kbd>→</kbd> horizontally (reversed in RTL), <kbd>↑</kbd> and <kbd>↓</kbd> vertically.

### API

Listen for `change` to do things like show the current slide number and total slides.

```html
<div class="carousel" id="my-carousel" …>…</div>
<p id="my-carousel-status">Slide 1 of 5</p>
```

```js
const carousel = document.getElementById("my-carousel");
const status = document.getElementById("my-carousel-status");

carousel.addEventListener("change", (event) => {
  const { index, count } = event.detail;
  status.textContent = `Slide ${index + 1} of ${count}`;
});
```
