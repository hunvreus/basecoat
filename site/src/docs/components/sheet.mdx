# Sheet

A modal panel for viewing or editing information alongside the current page.

      <p id="sheet-profile-description">Make changes to your profile here. Click save when you're done.</p>
    </header>
    <section class="px-4">
      <form id="sheet-profile-form" method="dialog" class="grid gap-6">
        <div class="grid gap-3">

## Usage

<Steps>
  <Step title="Include CSS">

Import Tailwind and one full Basecoat style bundle.

```css
@import 'tailwindcss';
@import 'basecoat-css/vega.css';
```

For individual imports, include the base CSS, the components you use, and one style pack.

```css
@import 'tailwindcss';
@import 'basecoat-css/base/base.css';
@import 'basecoat-css/components/button.css';
@import 'basecoat-css/components/sheet.css';
@import 'basecoat-css/styles/vega.css';
```

Using CDN or bundler imports? See the [Installation page](/installation).

  </Step>
  <Step title="Include JavaScript">

Copy or serve the full Basecoat JavaScript bundle.

```html
<script src="/assets/js/all.min.js" defer></script>
```

Or copy or serve the Basecoat runtime and Drawer script.

```html
<script src="/assets/js/basecoat.min.js" defer></script>
<script src="/assets/js/drawer.min.js" defer></script>
```

Using CDN or bundler imports? See the [Installation page](/installation).

  </Step>
  <Step title="Add your sheet HTML">

Use `class="sheet"` on a native `<dialog>`. Sheet has its own component CSS and style-pack visuals. It uses the [Drawer](/components/drawer) script for dialog interactions. Set the edge with `data-side` (right by default), open the dialog with `showModal()`, and associate its heading with `aria-labelledby`.

```html
<button type="button" class="btn" data-variant="outline" onclick="document.getElementById('sheet-example').showModal()">Project details</button>
<dialog id="sheet-example" class="sheet" data-side="right" aria-labelledby="sheet-example-title">
  <article>
    <header>
      <h2 id="sheet-example-title">Project details</h2>
      <p>Review the information for this project.</p>
    </header>
    <footer>
      <button type="button" class="btn" onclick="this.closest('dialog').close()">Done</button>
    </footer>
  </article>
</dialog>
```

  </Step>
</Steps>

### HTML structure

<dl>
  <dt><code>&lt;dialog class="sheet" id="&#123; SHEET_ID &#125;"&gt;</code></dt>
  <dd>
    Native dialog. Associate its heading with <code>aria-labelledby</code>; use <code>data-side</code> to choose an edge.
    <dl>
      <dt><code>&lt;article&gt;</code></dt>
      <dd>
        Direct-child content surface. Another suitable container may be used.
        <dl>
          <dt><code>&lt;header&gt;</code> <span class="badge" data-variant="secondary">Optional</span></dt>
          <dd>Heading and description.</dd>
          <dt><code>&lt;section&gt;</code> <span class="badge" data-variant="secondary">Optional</span></dt>
          <dd>Scrollable body.</dd>
          <dt><code>&lt;footer&gt;</code> <span class="badge" data-variant="secondary">Optional</span></dt>
          <dd>Actions. Include a control that closes the dialog.</dd>
        </dl>
      </dd>
    </dl>
  </dd>
</dl>

Omit the close button to dismiss through the backdrop or Escape. Backdrop dismissal uses the Drawer script included in the setup above.

      <p id="sheet-no-close-description">This sheet doesn't have a close button in the top-right corner. Click outside to close.</p>
    </header>
  </article>
</dialog>
</Preview>
