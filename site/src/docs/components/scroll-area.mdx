## Usage

With a [Basecoat style bundle](/installation) loaded, give the viewport a height or width, enable scrolling on that axis, and add `scrollbar`. Make the viewport focusable so keyboard users can scroll it.

```html
<div class="scrollbar h-[200px] w-[350px] max-w-full overflow-auto rounded-md border p-4" role="region" tabindex="0" aria-label="Release notes">
  Your scrollable content here.
</div>
```

Scrollbar appearance and visibility follow the browser and operating system. See [Scrollbar](/utils/scrollbar) for Basecoat’s compact style and [Scroll Fade](/utils/scroll-fade) for fading the edges of a viewport.
