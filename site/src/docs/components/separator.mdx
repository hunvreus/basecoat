## Usage

<Steps>
  <Step title="Include CSS">

Import Tailwind and one full Basecoat style bundle.

```css
@import "tailwindcss";
@import "basecoat-css/vega.css";
```

Or import only the base CSS, which styles horizontal and vertical separators.

```css
@import "tailwindcss";
@import "basecoat-css/base.css";
```

Separator is a native `<hr>` and has no dedicated component CSS file.

Using CDN or bundler imports? See the [Installation page](/installation).

  </Step>
  <Step title="Add your separator HTML">

Use an `<hr>` with `role="separator"`. It renders as a 1px line in the `border` color, matching shadcn/ui's Separator.

```html
<hr role="separator" />
```

If the separator is purely decorative, use `role="none"` instead so assistive technologies skip it. This is what shadcn/ui's `decorative` prop does.

```html
<hr role="none" />
```

  </Step>
</Steps>

## Examples

### Vertical

Add `aria-orientation="vertical"` for a vertical separator. It fills the height of its row.

<Preview>

  <div>Docs</div>
  <hr role="separator" aria-orientation="vertical" />
  <div>Source</div>
</div>
</Preview>
