## Usage

<Steps>
  <Step title="Include CSS">

Import Tailwind and one full Basecoat style bundle.

```css
@import "tailwindcss";
@import "basecoat-css/vega.css";
```

Or import only the base CSS, which sets the border color.

```css
@import "tailwindcss";
@import "basecoat-css/base.css";
```

Separator is a native `<hr>` plus Tailwind utilities and has no dedicated component CSS file.

Using CDN or bundler imports? See the [Installation page](/installation).

  </Step>
  <Step title="Add your separator HTML">

Use an `<hr>`. Tailwind's preflight and Basecoat's base CSS render it as a 1px line in the `border` color, matching shadcn/ui's Separator.

```html
<hr role="separator" />
```

  </Step>
</Steps>

## Examples

### Vertical

Add `aria-orientation="vertical"` and swap the top border for an inline-start border. `self-stretch` makes it fill the height of a flex row.

  <div>Docs</div>
  <hr role="separator" aria-orientation="vertical" class="h-auto self-stretch border-t-0 border-s" />
  <div>Source</div>
</div>
</Preview>
