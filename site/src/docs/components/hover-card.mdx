## Usage

Load the full Basecoat CSS and JavaScript bundle, or use the runtime, `hover-card.js`, Popover CSS, Hover Card CSS, and a style pack.

```html
<div class="hover-card">
  <a href="/profile">Profile</a>
  <div data-popover aria-hidden="true">A preview of this profile.</div>
</div>
```

The preview is supplementary. Keep essential information at the linked destination. It opens on mouse hover or keyboard focus and stays open while focus moves into the preview. Escape dismisses an open preview and returns focus to its trigger when focus was inside the panel. Links remain usable on touch devices.

Use `data-delay` and `data-close-delay` on the trigger to change the delay in milliseconds. The defaults are 600 and 300. Set `data-side` and `data-align` on the panel to position it, as with Popover.

### HTML structure

<dl>
  <dt><code>&lt;div class="hover-card"&gt;</code></dt>
  <dd>
    Wrapper for the trigger and preview.
    <dl>
      <dt><code>&lt;a href="&#123; URL &#125;"&gt;</code> or <code>&lt;button type="button"&gt;</code></dt>
      <dd>Trigger. Use a link when it leads to the full content. Optional <code>data-delay</code> and <code>data-close-delay</code> set delays in milliseconds.</dd>
      <dt><code>&lt;div data-popover aria-hidden="true"&gt;</code></dt>
      <dd>Supplementary preview. JavaScript updates <code>aria-hidden</code> when the card opens and closes.</dd>
    </dl>
  </dd>
</dl>
