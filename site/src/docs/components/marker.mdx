## Usage

Use `.marker` on a semantic element. Place an optional decorative SVG before a `<span>` containing the text. Add `data-variant="separator"` or `data-variant="border"` for the other layouts. No JavaScript is required.

```html
<div class="marker" role="status">
  <svg aria-hidden="true" class="animate-spin motion-reduce:animate-none" xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="M21 12a9 9 0 1 1-6.219-8.56" /></svg>
  <span>Compacting conversation</span>
</div>
```

Use `role="status"` when the text updates dynamically, and hide decorative icons from assistive technology. A labeled separator needs no `role="separator"`; its text remains available to screen readers. Use a real `<a>` or `<button>` for actions.

### Shimmer

Use `shimmer` on text for an animated highlight. Text stays static in browsers without relative-color support, with reduced motion enabled, or in forced-colors mode.
