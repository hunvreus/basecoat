## Usage

Use `scroll-fade` on a vertical scroller or `scroll-fade-x` on a horizontal one. Both ship with each Basecoat style bundle and work with Tailwind’s `@apply`. Put the border on a wrapper so the mask affects only the scrolling content.

```html
<div class="scroll-fade max-h-48 overflow-y-auto" tabindex="0" aria-label="Release notes">
  <!-- Release notes -->
</div>
```

The mask follows the native scroll position using CSS scroll-driven animations. Browsers without support show the content normally, as does forced-colors mode. The horizontal fade follows the reading direction in RTL.

Use the same utility inside a Tailwind rule for a custom list:

```css
.file-strip {
  @apply scroll-fade-x overflow-x-auto [scrollbar-width:none] [&::-webkit-scrollbar]:hidden;
}
```

## RTL

## Where Basecoat uses it

[Attachment](/components/attachment) applies the horizontal fade to scrolling groups and clears the mask when focus enters the group. [Code Block](/components/code-block) applies a horizontal fade to long source lines and a vertical fade to wrapped output. Both components supply the fade in their CSS.
